# 明鉴草书黑体

*（感谢[NaitLee](https://unseen-site.fun/about/#reach-out)基于本站制作了网页版，您可以[点击此处](https://草书.unseen-site.fun/font/alpha-download.html)浏览。）*

这是一款笔画清晰明确的开源草书黑体字库。字库为下列用途精心设计：
* **书法参考**
	* 字形**清晰明了**，以黑体作为表现形式，呈现今草字形。具有传统字帖和书法字典无法相比的**清晰性**、**系统性**和**规范性**。
	* 字形**严谨考究**，字字用形参考两千年各代书法名家，兼逐字严格分析构型结构，呈现最为地道规范草书字形，规避了以往字帖和参考资料中充斥的异写形和讹形。一些有多种写法的字，还补充有额外的可选字形。
* **草书初学**
	* 字形**识别度高**，适合初学熟悉草书的爱好者在日常使用中快速熟悉草书字形。
* **日常使用**
	* 字形**简洁易读**，具备信息时代黑体字的美观性，非常适合在**电子设备**、**招牌海报**中取代一般黑体字大量使用。
* **艺术设计**
	* 字形**现代简约**，适合取代楷书黑体字出现在各种应用场景。字库完全开源，可以免费自用商用。

## 字库内容

| 字表 | 覆盖范围 |
| --- | ---: |
| 《现代汉语常用字表》（1988年） | 3,500字 |
| GB 2312 | 6,763字 |
| GB/T 12345 | 6,866字 |
| 《常用國字標準字體表》（台湾） | 4,808字 |
| 《常用字字形表》（香港） | 4,762字 |
| 《常用漢字表》（日本） | 2,136字，另含364个旧字体 |
| 《漢文敎育用基礎漢字》（韩国） | 1,800字 |

另外包含标点、西文（拉丁）和数字。

初版完成后，持续改进字库中。将来还将继续校对字形、改善美观性、增加多种自重、扩充字库覆盖。敬请期待。

## 制作流程

本开源库除了发布明鉴草书黑体，也分享字体（草书）制作的流程。您可以在[这个文档](WorkFlow.md)找到字体制作流程的描述。

项目中的 Glyphs 工具可[直接从终端启动](tools/README.md#从终端运行-glyphs-工具)，脚本保留在项目内，路径自动定位。
完整工具列表及使用说明见[工具文档](tools/README.md)。

因为本字体的诞生较为坎坷，所以制作流程并不十分完整。作者计划以后继续制作其它草书字体，届时会分享更加完整优化的制作流程。
